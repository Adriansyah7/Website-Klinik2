# Klinik Kesehatan Mental Matahari

Landing page modern, simple, dan responsive untuk klinik kesehatan mental.

## Struktur
- `index.html` — struktur landing page
- `style.css` — desain responsive/mobile-first
- `script.js` — menu mobile, FAQ native accordion, dan reveal animation

## Cara menjalankan
Buka `index.html` langsung di browser, atau jalankan server lokal seperti:

```bash
python -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Sebelum dipakai production
Ganti nomor WhatsApp, email, alamat, sosial media, jam operasional, dan testimoni placeholder dengan data klinik yang sebenarnya.
